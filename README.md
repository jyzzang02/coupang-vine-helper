# Coupang Vine Helper

> **한국어 안내** | 체험단 상품을 더 빠르게 비교하기 위한 개인용 Chrome 확장 프로그램 (실험 단계)

브라우저에 이미 표시된 쿠팡체험단 상품명·가격·재고 문구를 분석해 사용자 정의 가중치에 따라 추천 순위를 표시합니다. 최종 상품 신청은 사용자가 **모바일 쿠팡 앱에서 직접** 진행합니다.

## 주요 기능

- 최우선 키워드, 선호 키워드, 제외 키워드 및 가격·카테고리 가중치
- 상품 목록 자동 스크롤과 신규 상품 등장 시 추천 순위 재계산
- 실제 페이지 상품 카드에 순위 배지 표시
- `N개 남음`은 추천에 포함, `모두 소진`은 추천에서 제외
- **ON/OFF 자동 새로고침**: 기본 OFF, 30초/60초/2분/5분 선택, 숨긴 탭·닫힌 분석창에서 중지
- **가격 점수 '이번 목록 기준'**: 신청 가능한 상품들의 가격 중앙값 대비 상대가격을 계산 (비공식 가격대 추정)
- 수동·자동 새로고침 전후 재고 스냅샷 비교
- 쿠팡 사이트에 접속하지 않고 시험할 수 있는 오프라인 시뮬레이터

## 설치 및 사용

1. 저장소의 `extension` 폴더를 준비합니다.
2. Chrome 주소창에서 `chrome://extensions` 실행 → **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더 선택.
4. 쿠팡에 직접 로그인한 후 `https://my.coupang.com/productreview/adventurer/productList`로 이동합니다.
5. 최초 안내창은 직접 닫고, 화면의 **상품 분석** 버튼을 눌러 설정과 추천 순위를 확인합니다.
6. 자동 스크롤을 켜고, 원할 때만 **자동 새로고침**을 ON으로 전환합니다. 주기는 30초 이상 (기본 60초).
7. 새로고침 전후 재고 수량이 비교되며, 현재 회차의 상품 가격 중앙값을 기준으로 순위가 갱신됩니다.
8. 선택한 상품은 **휴대전화에서 직접 신청**합니다.

### 오프라인 테스트

확장 프로그램 아이콘 → **가상 상품 테스트 페이지 열기** → 안내창의 **상품보기** → **상품 분석** → **자동 스크롤 시작**. 테스트 페이지에서 다음 재고 상태를 준비하고 F5를 누르면 변경 수량 비교를 시험할 수 있습니다.

점수 계산 테스트:

```bash
node test/rules.test.js
```

## 범위 및 주의사항

- **자동 로그인, 상품 신청, 쿠폰 발급, 주문은 하지 않습니다.** 새로고침은 사용자가 켰을 때만 브라우저의 `location.reload()`를 실행하며, 별도 쿠팡 API 요청이나 보안 인증 우회는 포함하지 않습니다.
- 자동 스크롤이 페이지의 지연 로딩을 발생시킬 수 있습니다.
- 재고 숫자는 마지막으로 페이지를 로드한 시점의 값입니다. 실제 구매 가능 여부나 재고 유지를 보장하지 않습니다.
- 실제 쿠팡체험단 공개 상품 페이지의 HTML 구조로 검증되지 않았습니다. 오프라인 테스트 통과는 실제 서비스 호환성을 입증하지 않습니다.
- 가상 테스트 화면에 포함된 일부 상품 썸네일은 사용자가 제공한 스크린샷에서 분리된 시뮬레이션 자료입니다. 임의 재배포에 주의하세요.
- 쿠팡 공식 서비스가 아니며, 서비스 정책에 따른 사용 제한 가능성이 있습니다.

## 프로젝트 구조

```text
extension/
  manifest.json      # Chrome Manifest V3
  scoring.js         # 키워드/가격/카테고리 기반 점수 계산
  content.js         # DOM 분석, 스크롤, 재고 비교, 추천 배지
  popup.html         # 확장 프로그램 팝업
  test/              # 오프라인 모의 페이지 및 자료
test/
  rules.test.js      # Node.js 점수 계산 테스트
README_설치방법.md     # 한국어 상세 설치 및 시험 방법
CHANGELOG.md          # 버전별 변경 이력
```

## v0.8 평가 방식과 주의

- 자동 새로고침은 **기본 OFF** (최소 30초)이며 분석창이 닫혔거나 탭이 숨겨지면 일시중지됩니다. 페이지 새로고침은 서비스 정책에 따라 제한될 수 있습니다.
- 쿠팡체험단의 1만원/5만원/30만원/100만원 구분은 사용자의 경험적 관찰이며 **쿠팡의 공식 가격대 규칙으로 확인된 것이 아닙니다.**
- 가격 점수는 이번 회차에서 확인한 신청 가능 상품의 **중앙값 대비 상대가격**이 기본값입니다. 스크롤하면서 새 상품이 발견되면 중앙값과 추천 순위가 바뀔 수 있습니다.
- 자동 새로고침은 완전한 재고 동기화를 보장하지 않으며, 실제 공개 상품 페이지에서의 최종 검증이 필요합니다.
