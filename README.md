# Coupang Vine Helper

> **한국어 안내** | 체험단 상품을 더 빠르게 비교하기 위한 개인용 Chrome 확장 프로그램 (실험 단계)

브라우저에 이미 표시된 쿠팡체험단 상품명·가격·재고 문구를 분석해 사용자 정의 가중치에 따라 추천 순위를 표시합니다. 최종 상품 신청은 사용자가 **모바일 쿠팡 앱에서 직접** 진행합니다.

## 주요 기능

- 최우선 키워드, 선호 키워드, 제외 키워드 및 가격·카테고리 가중치
- 상품 목록 자동 스크롤과 신규 상품 등장 시 추천 순위 재계산
- 실제 페이지 상품 카드에 순위 배지 표시
- `N개 남음`은 추천에 포함, `모두 소진`은 추천에서 제외
- **ON/OFF 자동 새로고침**: 기본 OFF, 5초/10초/15초/20초/30초 선택, 숨긴 탭·닫힌 분석창에서 중지, 새로고침 뒤 순위 복원
- **가격 점수 '이번 목록 기준'**: 신청 가능한 상품들의 중앙값 대비 상대가격 계산 (비공식 가격대 추정)
- 수동·자동 새로고침 전후 재고 스냅샷 비교
- 쿠팡 사이트에 접속하지 않고 시험할 수 있는 오프라인 시뮬레이터

## 설치 및 사용

1. 저장소의 `extension` 폴더를 준비합니다.
2. Chrome 주소창에서 `chrome://extensions` 실행 → **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더 선택.
4. 쿠팡에 직접 로그인한 후 `https://my.coupang.com/productreview/adventurer/productList`로 이동합니다.
5. 최초 안내창은 직접 닫고, 화면의 **상품 분석** 버튼을 눌러 설정과 추천 순위를 확인합니다.
6. 자동 스크롤을 켜고, 원할 때만 **자동 새로고침**을 ON으로 전환합니다. 주기 5·10·15·20·30초 중 선택 (기본 OFF).
7. 새로고침 전후 재고 수량이 비교되며, 현재 회차의 상품 가격 중앙값을 기준으로 순위가 갱신됩니다.
8. 선택한 상품은 **휴대전화에서 직접 신청**합니다.

### 오프라인 테스트

확장 프로그램 아이콘 → **가상 상품 테스트 페이지 열기** → 안내창의 **상품보기** → **상품 분석** → **자동 스크롤 시작**. 테스트 페이지에서 다음 재고 상태를 준비하고 F5를 누르면 변경 수량 비교를 시험할 수 있습니다.

점수 계산 테스트:

```bash
node test/rules.test.js
```

## 범위 및 주의사항

- **자동 로그인, 상품 신청, 쿠폰 발급, 주문은 하지 않습니다.** 새로고침은 사용자가 켰을 때만 `location.reload()`를 통해 실행하고, 별도 쿠팡 API 요청이나 인증 우회는 포함하지 않습니다.
- 자동 스크롤이 페이지의 지연 로딩을 발생시킬 수 있습니다.
- 재고 숫자는 마지막으로 페이지를 로드한 시점의 값입니다. 실제 구매 가능 여부나 재고 유지를 보장하지 않습니다.
- 실제 쿠팡체험단 공개 상품 페이지의 HTML 구조로 검증되지 않았습니다. 오프라인 테스트 통과는 실제 서비스 호환성을 입증하지 않습니다.
- 가상 테스트 화면에 포함된 일부 상품 썸네일은 사용자가 제공한 스크린샷에서 분리된 시뮬레이션 자료입니다. 임의 재배포에 주의하세요.
- 쿠팡 공식 서비스가 아니며, 서비스 정책에 따른 사용 제한 가능성이 있습니다.

## 프로젝트 구조

```text
extension/
  manifest.json      # Chrome Manifest V3
  scoring.js         # 키워드/가격/카테고리 기반 점수 계산
  content.js         # DOM 분석, 스크롤, 재고 비교, 추천 배지
  popup.html         # 확장 프로그램 팝업
  test/              # 오프라인 모의 페이지 및 자료
test/
  rules.test.js      # Node.js 점수 계산 테스트
README_설치방법.md     # 한국어 상세 설치 및 시험 방법
CHANGELOG.md          # 버전별 변경 이력
```

## 리뷰 작성 페이지 테스트 (v0.8.1)

- `https://my.coupang.com/productreview/reviewable`에서 일반 구매 상품명 인식과 키워드 우선순위/제외/자동 스크롤을 테스트할 수 있습니다.
- 체험단 상품이 아니므로 상품 가격·재고·신청 가능 여부는 분석하지 않습니다. 자동 새로고침은 별도 ON/OFF 설정으로 사용할 수 있습니다.
- 실제 쿠팡 리뷰 페이지의 HTML 구조가 달라 테스트 인식률이 낮을 수 있습니다.

## v0.8.2: 리뷰 작성 페이지 자동 새로고침

- 리뷰 작성 목록에서도 자동 새로고침 ON/OFF 및 간격(5·10·15·20·30초)을 선택할 수 있습니다. 기본값 OFF.
- 체험단 목록과 리뷰 작성 목록의 새로고침 설정은 서로 독립적입니다.
- 리뷰 입력창/편집 내용이 감지되면 새로고침을 보류하고 상태를 표시합니다.
- 브라우저 탭이 비활성화되거나 분석 패널을 닫으면 자동 새로고침을 멈춥니다.
- 사용자가 리뷰 작성을 저장하기 전에는 직접 F5 새로고침도 피하세요. 자동 보호는 쿠팡의 모든 편집 UI를 완벽하게 탐지한다고 보장하지 않습니다.

## v0.8.3 새로고침 조건

- 체험단·리뷰 작성 페이지 각각 ON/OFF 및 5·10·15·20·30초 주기를 설정할 수 있습니다. 기본은 OFF입니다.
- **자동 스크롤 실행 중** 더 내려갈 수 없고 새 항목도 4회 연속 나타나지 않으면 자동 새로고침합니다.
- 체험단 목록은 아래로 스크롤한 다음 **새롭게 화면에 등장한 품절 상품**이 있으면 갱신합니다. 리뷰 목록에는 재고가 없으므로 이 조건이 적용되지 않습니다.
- 조건부 갱신도 **5초 이상 간격**을 유지합니다. 새로고침 후 분석 창과 자동 스크롤은 다시 열립니다.
- 리뷰 작성창·입력 감지 중, 창을 닫았거나 탭이 비활성일 때는 자동 새로고침을 중지하거나 보류합니다.
- 빈 목록에 대한 반복 새로고침은 쿠팡 서버 요청을 유발하므로 과도한 사용에 주의하세요. 실제 쿠팡 페이지에서의 호환성은 계속 확인이 필요합니다.
## v0.8.4: 위치 이동 후 30초 새로고침 유예

- 상품 추천 목록에서 **위치** 버튼 클릭 시 자동 스크롤은 즉시 중지하고 해당 상품으로 이동합니다.
- 자동 새로고침 ON 상태에서는 **위치를 누른 시점부터 30초간** 주기 갱신 및 조건부 즉시 갱신을 모두 보류합니다. 이후 자동 새로고침이 다시 작동합니다.
- 30초가 지나기 전에 다른 상품의 **위치**를 다시 누르면 유예 시간이 다시 30초로 초기화됩니다.
- 자동 새로고침 OFF 상태에서는 자동으로 갱신하지 않습니다. 상품 신청은 계속 사용자가 직접 진행합니다.

## v0.8.5: 상위 10개 추천과 CSV 기능 삭제

- 추천 목록과 상품 카드에 1~10위만 표시합니다. 모든 상품은 계속 분석해 순위가 바뀌면 TOP 10에 반영합니다.
- 1~3위: 빨강, 4~5위: 주황, 6~10위: 파랑으로 순위 번호와 카드 배지를 구분합니다.
- CSV 저장 버튼, CSV 생성/다운로드 코드를 삭제했습니다.
- 위치 클릭 후 자동 새로고침 30초 보류 기능은 그대로 유지됩니다.

## v0.8.6: 5만원 이하 회차 모의 환경

- 오프라인 테스트에 등장하는 모든 상품은 5만원 이하 가격군입니다.
- 페이지 접속 시 상품 8개만 나타나며 하단까지 스크롤할 때 350ms 로딩 지연 후 10개씩 나타납니다.
- 실제 쿠팡 서비스에서는 재고 정보가 새로고침 시점에만 변합니다. 테스트에서도 다음 재고 상태를 준비한 뒤 F5를 눌러야 변화합니다.
- 일반 쿠팡 상품 페이지 동작 및 자동 신청 기능은 변경하지 않았습니다.

## v0.8.7: 명확한 순위 색상과 설정 화면 개선

- TOP 10 색상은 **1~3위 빨강, 4~5위 노랑(짙은 글씨), 6~10위 파랑**입니다.
- **⚙ 가중치 설정** 버튼은 추천 목록을 대신하는 전용 편집 화면을 열며, **← 추천 목록**은 저장하지 않고 돌아갑니다.
- 최우선·선호·제외 키워드를 쉼표/줄바꿈으로 입력하고, 자주 사용하는 키워드는 빠른 추가 버튼으로 넣을 수 있습니다.
- 카테고리별 규칙은 각 키워드·슬라이더로 설정/추가/삭제합니다.
- 가격·선호 키워드·카테고리 중요도 슬라이더, 가격 평가 방식 및 최저·최고 가격 조건을 지원합니다.
- 설정을 저장하면 즉시 추천 순위에 반영됩니다. **기본값**은 입력폼만 바꾸며, 저장 전에는 실제 설정이 변경되지 않습니다.
- 설정 화면에서는 자동 스크롤·자동 새로고침이 일시 중단됩니다. CSV 기능과 자동 신청은 지원하지 않습니다.
