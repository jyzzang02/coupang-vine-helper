# 체험단 상품 우선순위 도우미 (실험용 v0.3)

**기능:** PC 쿠팡에 사용자가 이미 로그인하여 상품 목록을 띄운 경우, 현재 브라우저 화면의 HTML에 존재하는 상품만 찾아 우선순위 점수를 표시합니다. 최우선 키워드, 선호 키워드, 제외 키워드, 카테고리 점수, 가격 가중치, 가격 필터를 직접 설정할 수 있습니다.

**하지 않는 일:** 계정 자동 로그인, 자동 새로고침, 추가 웹 요청, 서버 API 호출, 신청/쿠폰 발급/주문 버튼 클릭, 보안 인증 우회.

> **주의:** 쿠팡의 실제 체험단 화면은 로그인 후에만 확인할 수 있고, 현재 배포본은 그 화면의 HTML 구조로 실증 테스트하지 않았습니다. 화면 구조가 다르면 상품이 0개로 표시되거나 가격이 부정확하게 읽힐 수 있습니다. 또한 화면 분석 도구라고 해서 쿠팡의 서비스 정책상 사용이 허용됨을 보증하는 것은 아닙니다.

## v0.3 수정 사항

- `my.coupang.com/productreview/reviewable` (리뷰 작성 목록)에서는 **상품 스캔을 완전히 차단**합니다. 이전 버전은 구매 내역을 체험단 상품으로 잘못 감지하는 문제가 있었습니다.
- 실제 체험단 목록 주소 `my.coupang.com/productreview/adventurer/productList`에서만 상품 후보를 읽습니다.
- '쿠팡체험단 상품이 없습니다' 상태에서 추천 결과를 0개로 고정합니다.
- 동일 상품명 중복 표시는 하나로 합칩니다.
- 실제 쿠팡에 상품이 공개된 상황의 HTML로 테스트한 것은 아니므로 그때는 추가 보정이 필요합니다.

## v0.2 수정 사항

- 체험단 페이지의 실제 주소인 `https://my.coupang.com/productreview/adventurer/productList`에서도 상품 분석 버튼을 표시하도록 수정했습니다. 기존 v0.1은 이 주소를 누락했습니다.
- 상품이 없는 상태에도 분석 버튼이 나타나며, 열면 0개라고 안내합니다.

## 윈도우 크롬 설치

1. ZIP 파일의 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions/`를 입력합니다.
3. 우측 상단 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
5. 압축을 푼 폴더의 `extension` 폴더를 선택합니다.
6. 기존 버전이 설치되어 있다면 Chrome 확장 프로그램 페이지에서 삭제하거나, 기존 `extension` 폴더 내용을 v0.3으로 교체하고 **확장 프로그램의 새로고침(↻)** 버튼을 누릅니다.
7. 평소대로 쿠팡에 직접 로그인하고 쿠팡체험단 상품 목록 페이지(`my.coupang.com/productreview/adventurer/productList`)를 엽니다. **이미 열린 쿠팡 탭에서도 Ctrl+R로 페이지를 새로고침해야 합니다.**
8. 우측 하단 **🔎 상품 분석** 버튼을 클릭합니다.
9. **⚙ 가중치 설정**에서 키워드·제외 조건·가격 기준을 정하고 저장합니다.
10. 표시된 상품을 정렬한 목록과 점수를 확인합니다. 새 상품이 브라우저 화면에 추가로 로딩되면 자동으로 목록을 갱신합니다. **CSV 저장**으로 결과를 내보낼 수도 있습니다.

## 점수 체계

- **최우선 키워드:** 상품명에 하나라도 포함되면 기본 **+1000점**. 이 키워드에 해당하는 상품은 다른 일반 상품보다 항상 우선됩니다.
- **선호 키워드:** 일치하면 `키워드 가중치`에 해당하는 점수 추가.
- **카테고리:** `상품명에 포함된 단어:선호 점수(0~100)`를 줄별로 입력. `카테고리 가중치 × 선호 점수/100`이 추가됩니다.
- **가격:** 가격 가중치 × min(가격/가격 점수 만점 기준, 1). 예) 가격 가중치 80, 만점 기준 40만원에서 20만원 상품은 40점, 40만원 이상은 80점.
- **제외 키워드:** 해당 단어가 포함된 상품은 점수 계산에서 제외.
- **필터:** 최소/최대 가격과 마감·품절 상태에 따른 제외.

※ **가격은 화면에서 추정한 값**이며, 쿠팡의 실제 혜택 가격이나 체험단 적용 금액과 다를 수 있습니다. 상품명과 가격을 반드시 앱에서 재확인하세요.

## 제약 사항

- 현재 DOM(브라우저가 로딩해 둔 화면)에서만 찾습니다. 화면에 아직 로딩되지 않은 다른 페이지 상품은 스캔하지 않습니다.
- 쿠팡의 화면 구조가 바뀌면 상품 인식 로직을 수정해야 합니다.
- 자동 스크롤, 서버 직접 요청, 자동 클릭은 없습니다. 사용자가 직접 스크롤해서 나타난 상품만 추가 인식합니다.
- 결과의 `복사` 버튼은 **상품명**을 복사합니다. 앱에서 직접 상품을 선택하는 데 참고하세요.
- 이 확장 프로그램은 사용자 컴퓨터에 설정값만 저장하며, 제품 데이터를 개발자 서버로 전송하지 않습니다.
- 실제 쿠팡 계정에서 검증되지 않은 시험 버전입니다. 로그인 쿠키/비밀번호를 확장 프로그램이 읽거나 저장하지 않도록 만들었습니다.

## 테스트

`test/demo.html`은 가상 상품 목록이므로 쿠팡과 관계가 없습니다. 내부 점수 테스트는 `node test/rules.test.js`로 수행합니다. 실제 상품 인식은 쿠팡 체험단 웹 화면 HTML/스크린샷 기반 보정이 필요할 수 있습니다.
