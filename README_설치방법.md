# 체험단 상품 우선순위 도우미 v0.6

**용도:** 사용자가 직접 로그인해서 열어 놓은 **쿠팡체험단 상품 목록 페이지**에서 상품명을 읽고 선호 조건별 점수를 계산하는 크롬 확장 프로그램입니다. **상품 신청은 사용자가 휴대폰에서 직접 진행**합니다.

## v0.6 기능

- **자동 스크롤:** 우측 하단 `🔎 상품 분석` → `↡ 자동 스크롤 시작`. 사이트에 보이는 스크롤 영역을 내려가면서 상품을 누적 수집합니다. 느리게/보통/빠르게 속도 선택 가능. `■ 스크롤 중지` 버튼으로 언제든 멈출 수 있습니다.
- **실시간 추천 순위:** 스크롤 중 새로운 카드가 읽히면 상품별 점수를 재계산하여 순위 창을 갱신합니다. 수동 스크롤도 지원합니다. 이미 지나간 상품도 누적 목록에 남습니다.
- **쿠팡 상품 카드에 직접 표시:** 상위 10개 상품에는 `★ 추천 1위 · 1200점`처럼 작은 순위 배지가 붙고, 순위가 변하면 배지도 바뀝니다. 원본 상품/신청 버튼을 클릭하거나 수정하지 않습니다.
- **현재 1위 고정 표시:** 분석 창 상단에서 현재 추천 1위 상품을 계속 볼 수 있으며, 1위 변경 시 표시가 강조됩니다.
- **위치 버튼:** 해당 상품 카드가 현재 페이지에 존재하면 자동 스크롤을 중단하고 해당 상품 위치로 이동합니다.
- **중복 제거·제외 키워드·우선순위 키워드·가격 점수·CSV 저장** 기능은 그대로 유지합니다.

## 실제 쿠팡 없이 오프라인 테스트하기 (v0.6)

1. 확장 프로그램 v0.6을 설치하고 크롬 오른쪽 위의 **퍼즐 아이콘 → 체험단 상품 우선순위 도우미**를 클릭합니다.
2. 팝업의 **「🧪 가상 상품 테스트 페이지 열기」**를 눌러 확장 프로그램 내부 테스트 화면을 엽니다.
3. 오른쪽 아래 **「🔎 상품 분석」 → 「↡ 자동 스크롤 시작」**을 누릅니다.
4. 가상 상품 48개가 12개씩 지연 표시되면서 순위가 계속 재계산되는지 확인합니다.
5. **「최우선 상품 등장시키기」**를 누르면 새 상품이 추가되고 1위가 바뀌는지 확인할 수 있습니다(기본 가중치 기준).
6. **「⚙ 가중치 설정」**에서 최우선 `노트북`, 제외 `케이스`, 가격 가중치 등을 바꿔 추천 결과를 확인합니다.
7. 상품 카드의 `추천 1위` 배지와 도우미 순위창이 같은지, 스크롤 중지 후 멈추는지 확인합니다.

테스트 화면은 확장 프로그램에 함께 들어 있는 HTML·JS 파일로만 동작합니다. **쿠팡 및 외부 서버에 요청하지 않으며 가상 상품 데이터만 사용**합니다. 이 테스트는 상품 점수·UI·스크롤 기능 확인용이며, **실제 쿠팡의 상품 목록 구조가 같다는 보장은 없습니다**.

## 설치 / 버전 교체

1. 새 ZIP을 압축 해제합니다.
2. 크롬에서 `chrome://extensions/`를 엽니다.
3. 기존 v0.1~v0.4는 삭제하거나 비활성화합니다. **여러 버전을 동시에 켜지 마세요.**
4. 오른쪽 위 `개발자 모드`를 켭니다.
5. `압축해제된 확장 프로그램을 로드합니다`를 누르고, 압축을 푼 `extension` 폴더를 선택합니다.
6. 쿠팡에 **직접 로그인**한 상태로 `https://my.coupang.com/productreview/adventurer/productList`를 열고 **Ctrl+R**로 새로고침합니다.
7. 오른쪽 아래 `🔎 상품 분석` → `⚙ 가중치 설정`으로 선호 키워드 등을 저장합니다.
8. `↡ 자동 스크롤 시작`을 누르면 목록을 내리면서 상품 스캔과 추천 순위 갱신을 진행합니다. `■ 스크롤 중지`로 멈춥니다.
9. 최종 쿠폰 발급 / 신청은 **휴대폰 쿠팡 앱에서 직접** 합니다.

## 동작 범위와 제한

- **지정된 체험단 상품 목록 페이지에서만 상품 분석**을 수행합니다. `/productreview/reviewable` 등 리뷰 작성·구매 이력은 분석하지 않습니다.
- 상품이 공개되지 않아 `쿠팡체험단 상품이 없습니다.` 문구가 나오는 경우 스캔할 상품이 없으며 자동 스크롤을 시작하지 않습니다.
- 페이지에 원래 보이지 않는 상품을 API로 별도 요청하지 않습니다. 다만 **스크롤로 사이트 자체의 지연 로딩이 실행되면 쿠팡 사이트가 자체적으로 데이터를 불러올 수 있습니다.**
- 페이지 새로고침, 외부 HTTP 요청, 자동 로그인, 자동 신청, 상품 선택/주문 버튼 클릭, 인증 우회 기능이 없습니다.
- 자동 스크롤은 **한 번 시작할 때 최대 80단계**를 진행하며, 내용이 늘어나지 않고 더 내려갈 수 없으면 자동 종료합니다.
- 브라우저 화면이 실제 쿠팡체험단 상품 목록 DOM과 다르면 인식이 실패할 수 있습니다. 상품명·가격은 화면으로부터 **추정**된 값입니다. 실제 쿠팡체험단 상품 화면은 검증되지 않았으며, 정상 동작을 보장하지 않습니다.
- 확장 프로그램은 선호 설정값을 **브라우저 로컬 저장소**에 저장합니다. 비밀번호나 로그인 쿠키를 읽거나 수집하거나 외부로 전송하는 코드는 없습니다.
- 쿠팡의 자동화 관련 이용 정책에서 본 보조도구 사용까지 허용되는지 확인된 것은 아닙니다.

## 순위 산정

- **최우선 키워드:** 이름에 포함되면 `+1000점` 이상 가점. 다른 일반 제품보다 항상 우선합니다.
- **선호 키워드:** 지정한 단어가 있으면 `선호 키워드 가중치` 적용.
- **카테고리:** 상품명 키워드로 카테고리 점수를 부여합니다.
- **가격:** `가격 가중치 × min(상품 추정 가격 / 가격 점수 만점 기준 가격, 1)`.
- **제외 키워드:** 포함된 제품은 추천 목록에서 제외합니다.
- **신청 마감/품절 및 가격 필터** 지원. 가격이 인식되지 않으면 가격 필터가 완전히 작동하지 않을 수 있습니다.

## 내부 테스트

쿠팡과 무관한 가상 상품 DOM으로 다음 항목을 자동 검증했습니다.

- `node test/rules.test.js`: 점수 계산
- `python test/browser_smoke.py`: 상품 스캔·중복/차단·변경 감지
- `python test/features_v04.py`: 자동 스크롤 중지·종료·순위 배지 중복 방지
- `python test/live_ranking_v05.py`: **수동 스크롤 중 신규 상품 등장 → 1위 즉시 변경 → 카드 배지 동기화**

정확한 상품 카드 위치와 가격은 실제 체험단 상품 공개 이후 추가 테스트가 필요합니다.
