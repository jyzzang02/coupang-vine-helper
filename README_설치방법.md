# 체험단 상품 우선순위 도우미 v0.8.1

크롬 확장 프로그램. 로그인된 페이지의 화면에 이미 나타난 상품 정보를 읽어 로컬에서 우선순위를 계산합니다. **자동 신청, 주문, 쿠폰 발급은 하지 않으며, 자동 새로고침은 기본 OFF입니다.**

## 설치

1. 기존 v0.6 확장 프로그램은 삭제하거나 비활성화합니다.
2. ZIP 압축을 풀고 크롬 주소창에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → 압축을 푼 `extension` 폴더를 선택합니다.
5. 쿠팡체험단 탭을 새로고침합니다.

## 오프라인 실습 (실제 쿠팡 접속 없이 진행)

1. 크롬 오른쪽 위 **체험단 상품 우선순위 도우미** 확장 아이콘을 누릅니다.
2. **가상 상품 테스트 페이지 열기**를 누릅니다.
3. 첫 진입 안내창의 **상품보기** 또는 `×` 버튼을 눌러 안내창을 닫습니다.
4. 오른쪽 아래 **상품 분석** 버튼을 눌러 추천 순위를 엽니다.
5. **자동 스크롤 시작**을 누르면 12개씩 92개까지 차례로 등장하고, 새 상품을 발견할 때마다 추천 순위가 다시 계산됩니다.
6. **모두 소진**은 회색 글씨이며 추천 대상에서 제외합니다. **N개 남음**은 추천 대상에 포함합니다.
7. 테스트 페이지의 **다음 재고 상태 준비** 버튼을 누른 다음 **F5**를 누릅니다. 화면을 새로고침하기 전까지 수량은 바뀌지 않습니다. 새로고침 이후 이전 값과 변경 값을 비교해 보여줍니다.
8. 설정에서 가격 점수는 **이번 목록의 상대가격**(기본) 또는 **고정 목표가격**으로 선택할 수 있습니다.
9. 새로고침 ON/OFF, 주기와 재고 상태 변화도 모의 화면에서 시험할 수 있습니다.

## 실제 쿠팡체험단 화면 사용

1. 사용자가 직접 쿠팡에 로그인합니다.
2. `https://my.coupang.com/productreview/adventurer/productList` 페이지를 엽니다.
3. 첫 진입 안내창이 나타나면 사용자가 직접 **상품보기** 버튼을 누릅니다.
4. 오른쪽 아래 **상품 분석** → **자동 스크롤 시작**을 누릅니다.
5. 이 프로그램은 상품명, 가격, `N개 남음`/`모두 소진` 상태를 로컬에서 읽고 우선순위를 보여 줍니다.
6. 필요하면 **자동 새로고침 ON**을 켜고 5초/10초/15초/20초/30초 중 주기를 선택합니다. (기본 OFF) 숨긴 탭에서는 새로고침을 일시중지합니다.
7. 새로고침 후 확장 프로그램이 이전 재고와 새 재고를 비교합니다. 목록을 다시 스캔하며, 최종 신청은 사용자가 진행합니다.
8. 최종 신청은 휴대전화 쿠팡 앱에서 직접 진행합니다.

## 주의사항 및 검증 범위

- **v0.8.1은 사용자가 제공한 화면을 바탕으로 만든 추정 인식기입니다. 실제 체험단 상품 공개 화면의 HTML 구조는 확보하지 못해 직접 검증하지 못했습니다.** 따라서 정식 페이지에서는 추출 실패나 숫자 인식 오류가 있을 수 있습니다.
- 재고 숫자는 **현재 쿠팡 페이지가 로드된 시점의 스냅샷**입니다. 실시간 재고 서버 조회 기능이 아니며, F5 후에도 그 숫자가 실제 신청까지 유지된다는 보장은 없습니다.
- 재고 비교를 위해 **상품명과 남은 수량을 기기 내 확장 프로그램 저장소에 보관**합니다. 로그인 세션·계정 정보는 저장하지 않습니다.
- 자동 스크롤은 사이트의 기존 화면 로딩을 유발할 수 있습니다. 별도 쿠팡 API 요청이나 인증 우회는 하지 않습니다. 사용자가 자동 새로고침을 ON으로 켜면 브라우저의 페이지 재로딩이 발생합니다.
- 오프라인 테스트용 상품명·가격·사진은 시뮬레이션 자료입니다. **실제 현재 판매 상품·체험단 재고가 아닙니다.** 사진은 사용자가 제공한 상품목록 캡처에서 상품 썸네일 부분만 잘라 사용했습니다.

## 파일

- `extension/`: 크롬에서 로드할 폴더
- `extension/scoring.js`: 가중치·필터·추천 점수 계산
- `extension/content.js`: 상품 인식, 상태 분류, 스크롤, 추천 표시
- `extension/test/demo.html`, `demo.js`, `images/`: 오프라인 연습 화면
- `test/rules.test.js`: 점수 계산 테스트

## 새로고침·가격 평가 참고

- 자동 새로고침은 **기본 OFF**, 최소 5초입니다. 쿠팡 이용정책에 따른 접속 제한 가능성이 있으니 사용에 주의하세요.
- 분석창을 닫거나 탭을 다른 곳으로 전환한 동안에는 새로고침하지 않습니다. 자동 스크롤 중이면 완료 후 확인 여유를 둡니다.
- **회차별 가격대 구분은 공식 규칙이 아닙니다.** 관측된 신청 가능 상품의 중앙값으로 `1만원/5만원/30만원/100만원 이하` 등 추정 구간을 표기합니다.
- 상품 가격의 원화 절대값 대신, 회차 내 중앙값 대비 비율로 가격 점수를 부여합니다. 단, 추가 상품을 발견하면 중앙값과 순위는 바뀔 수 있습니다.

## 리뷰 작성 페이지 테스트

1. 로그인 후 `https://my.coupang.com/productreview/reviewable`로 이동합니다.
2. 우측 아래 [상품 분석]을 누릅니다.
3. 리뷰 상품 목록의 이름이 인식되는지와 자동 스크롤, 키워드 제외 기능을 확인하세요.
4. 리뷰 페이지에서도 자동 새로고침을 ON/OFF할 수 있지만, 가격과 재고는 인식하지 않습니다.

### v0.8.2 리뷰 작성 목록 새로고침

1. `https://my.coupang.com/productreview/reviewable`에서 확장 프로그램의 상품 분석 버튼을 누릅니다.
2. `자동 새로고침` 체크박스를 ON으로 전환하고 5초/10초/15초/20초/30초 중 간격을 선택합니다.
3. 설정은 체험단 페이지와 별도로 저장되고, 기본값은 모두 OFF입니다.
4. 리뷰 작성창이나 텍스트 입력이 감지되면 새로고침이 일시중지됩니다. 완료 전에는 직접 F5하지 마세요.
5. 분석 창을 닫거나 탭을 전환하면 자동 새로고침이 중지됩니다.

## v0.8.3 새로고침 조건

- 체험단·리뷰 작성 페이지 각각 ON/OFF 및 5·10·15·20·30초 주기를 설정할 수 있습니다. 기본은 OFF입니다.
- **자동 스크롤 실행 중** 더 내려갈 수 없고 새 항목도 4회 연속 나타나지 않으면 자동 새로고침합니다.
- 체험단 목록은 아래로 스크롤한 다음 **새롭게 화면에 등장한 품절 상품**이 있으면 갱신합니다. 리뷰 목록에는 재고가 없으므로 이 조건이 적용되지 않습니다.
- 조건부 갱신도 **5초 이상 간격**을 유지합니다. 새로고침 후 분석 창과 자동 스크롤은 다시 열립니다.
- 리뷰 작성창·입력 감지 중, 창을 닫았거나 탭이 비활성일 때는 자동 새로고침을 중지하거나 보류합니다.
- 빈 목록에 대한 반복 새로고침은 쿠팡 서버 요청을 유발하므로 과도한 사용에 주의하세요. 실제 쿠팡 페이지에서의 호환성은 계속 확인이 필요합니다.
### 위치 버튼과 자동 새로고침 (v0.8.4)

- 추천 상품 옆 **위치**를 누르면 그 상품으로 스크롤하고 자동 스크롤을 정지합니다.
- 자동 새로고침이 ON이면 30초간 주기·품절 발견·목록 끝 새로고침이 모두 보류됩니다.
- 타이머는 화면에 표시되며 다른 **위치** 버튼을 누르면 30초부터 다시 시작합니다.
- 자동 새로고침 설정이 OFF면 페이지는 자동 갱신되지 않습니다.

### 추천 순위 색상 (v0.8.5)

- 추천 목록과 원래 상품 카드에 상위 10개만 표시합니다.
- 1~3위는 빨강, 4~5위는 주황, 6~10위는 파랑으로 구분합니다.
- 전체 상품은 내부에서 계속 점수를 매깁니다. CSV 저장 기능은 제공하지 않습니다.

### v0.8.6 테스트 페이지 변경

1. 확장 프로그램 팝업에서 **가상 상품 테스트 페이지 열기**를 누릅니다.
2. 상품보기 후 **8개 상품만 보이는지** 확인합니다.
3. 하단으로 스크롤하면 약 350ms 뒤 **10개 상품이 추가**됩니다.
4. 모든 상품 가격은 **50,000원 이하**입니다.
5. **상품 분석 → 자동 스크롤 시작**으로 추가 로딩과 TOP 10 갱신을 확인합니다.
6. **다음 재고 상태 준비 → F5**로 재고 수량 및 품절 변경을 확인합니다.

### v0.8.7 설정 화면

1. 상품 분석에서 **⚙ 가중치 설정**을 누르면 추천 목록이 숨겨지고 별도의 설정 화면이 열립니다.
2. 키워드는 쉼표/줄바꿈으로 구분하거나 빠른 추가 버튼으로 넣습니다.
3. 카테고리를 추가/삭제하고 점수 슬라이더를 조절합니다.
4. 상대가격/목표가격 모드를 선택하고 **설정 저장 · 순위 갱신**을 누릅니다.
5. **← 추천 목록**을 누르면 저장되지 않은 변경사항은 취소됩니다.
6. 추천 색상은 1~3위 빨강, 4~5위 노랑, 6~10위 파랑입니다.

설정 편집 중 자동 새로고침은 일시 중단됩니다.

### v0.8.8 카테고리 빠른 선택

1. 상품 분석 → **가중치 설정** → **③ 카테고리별 선호도**를 엽니다.
2. 원하는 예시 카테고리를 누르면 아래 목록에 자동 추가됩니다. 다시 누르면 해당 규칙이 해제됩니다.
3. 각 행에서 점수(0~100)와 검색 키워드를 조절하거나 직접 새 카테고리를 추가하세요.
4. **설정 저장 · 순위 갱신**을 눌러야 변경이 실제 순위에 적용됩니다. 저장하지 않고 돌아가면 기존 설정이 유지됩니다.
5. 공식 쿠팡 카테고리와 직접 연결되는 방식이 아니라, 상품명에 포함된 단어를 인식하는 방식입니다.

### v0.8.9: 사이즈 및 호환성 필터

1. **가중치 설정 → 사용하지 않는 상품 제외**에서 아기/여성 전용 상품 자동 제외 여부를 확인하세요.
2. 자신의 의류·신발 사이즈를 선택하세요. 선택하지 않으면 해당 상품군을 추천하지 않습니다.
3. **내 기기와 호환되는 액세서리만**에서 휴대폰과 워치 모델을 확인하세요. 기본값은 갤럭시 S24+ 및 갤럭시워치6 44mm입니다.
4. 기존 제외 키워드에 `케이스`/`필름`이 있다면, 호환되는 상품도 제외하므로 직접 수정하세요.
5. 오프라인 테스트 페이지에서 F5를 여러 번 눌러 상품별 재고가 감소하고 품절로 바뀌는지 확인하세요.

상품명만으로 호환성·사이즈를 판별하며 상세 옵션은 자동 확인하지 않습니다.

### v0.8.10 품절 상품 순서 테스트

- 테스트 페이지에서 **F5**를 누르면 재고가 줄고, 품절 상품은 소진된 순서대로 아래에 쌓입니다.
- 재고가 남은 상품이 먼저 표시되고, 먼저 소진된 상품 다음에 나중에 소진된 상품이 추가됩니다.
- 스크롤로 계속 상품을 불러오면 품절 영역을 확인할 수 있습니다.
- 이 정렬은 실제 쿠팡 페이지에 적용되지 않습니다.
